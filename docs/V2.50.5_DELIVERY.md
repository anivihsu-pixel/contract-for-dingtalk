# v2.50.5 交付说明

## 版本范围

本包在 v2.50.4 交付基线上增加生产路由尾斜杠兼容修复，运行时版本号为 `v2.50.5`。

## 本次修复

- 保持 `url_route_must=true` 与 `route_complete_match=true`，继续禁止自动路由回退。
- 启用 `remove_slash=true`，统一处理代理或部署面板自动补尾斜杠的页面地址。
- 修复 `/login/`、`/dashboard/`、`/health/` 等显式路由在生产环境误报 404。

## 功能边界

- 当前版本不包含商机模块；源码中不提供商机菜单、路由、控制器或数据表。
- `business_type` 指项目和合同使用的业务类型，不代表商机功能。

## 验证结果

- `/login` 与 `/login/` 均返回 HTTP 200。
- `/dashboard` 与 `/dashboard/` 在未登录状态均正确跳转登录页。
- PHPUnit：106 tests / 332 assertions。
