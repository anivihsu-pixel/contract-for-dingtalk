# v2.50.6 交付说明

## 修复范围

本包修复空会话及空路径访问时的根入口稳定性，运行时版本号为 `v2.50.6`。

## 路由修复

- 根路径 `/` 直接映射 `Dashboard/index`，不再通过闭包跳转 `/dashboard`。
- 未登录访问由全局鉴权中间件统一跳转 `/login` 或 `/m/login`。
- 已登录访问根路径直接进入桌面驾驶舱，移动设备由控制器分流至 `/m`。
- 保留 `route_complete_match=true`、`url_route_must=true` 和 `remove_slash=true`。

## 功能边界

- 当前版本不包含商机模块。
- 本次无数据库结构变更。
