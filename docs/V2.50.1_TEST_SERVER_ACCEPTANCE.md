# v2.50.2 测试服务器验收清单

> 历史清单：当前 v2.50.4 已移除商机模块，本文中涉及商机的验收项不再适用。

## 部署前

1. 完整备份数据库与当前发布目录。
2. 从现网版本起按文件名顺序执行未登记迁移，必须包含 `migration_v2.50.0_business_closure.sql`、`migration_v2.50.1_permissions.sql`。
3. 配置 `APP_DEBUG=false`、`COOKIE_SECURE=true`、`DINGTALK_MOCK_MODE=false` 与正式 HTTPS `DINGTALK_APP_URL`。
4. 运行 `php think system:check`，所有项目必须 PASS。

## 业务验收

- PC 与移动端均可从可见导航进入合同、客户、审批、商机；直接访问无权页面必须返回 403。
- 移动端商机可搜索客户；未命中时新建客户，保存后应返回商机表单且客户已自动选中。
- 管理员在字典设置维护业务线；历史已使用项只能停用，不能影响历史展示。
- 商机可填写下一步动作；选择“已流失”必须填写流失原因；成交转合同/项目后业务线一致。
- 新建客户时信用代码重复必须拦截；名称或电话疑似重复须管理员明确确认。
- 项目执行人员能看项目进度但看不到毛利；财务/经理/总经理按授权查看毛利或维护成本。
- 全局搜索分别验证本人、本部门、全公司三种数据范围，不得返回越权结果。
- 普通合同导出不含税号；拥有 `export:sensitive` 权限并显式请求敏感导出时才包含税号，审计日志记录范围与字段。
- 手机端合同、客户、供应商、商机表单断网后输入仍保留；重复点击或重试只生成一条记录。

## 环境验收

- 真实钉钉免登、审批通知、抄送、失败重试与连续三次失败升级告警。
- 每日备份、每周加密异地备份；在隔离库完成一次恢复并记录时间与校验结果。
- HTTPS、Secure Cookie、生产密钥、最小权限数据库账号、日志轮转与健康探针。
- 使用业务、经理、财务、项目执行、总经理、管理员真实账号完成 UAT。
