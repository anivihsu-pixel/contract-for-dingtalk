# v2.50.4 交付说明

## 版本范围

本包合并 v2.48.0 至 v2.50.4 的工作区改动，运行时版本号为 `v2.50.4`。

## 本次交付重点

- 合同审批、签署、执行、回款、开票、归档生命周期闭环。
- 角色权限、数据范围、敏感导出、全局搜索和移动端幂等草稿。
- 客户备注、客户行业字典，以及项目/合同业务类型贯通。
- 移除框架合同/执行订单层级入口，保留合同与项目关联。

## 功能边界

- 当前版本不包含商机模块；源码中不提供商机菜单、路由、控制器或数据表。
- `business_type` 指项目和合同使用的业务类型，不代表商机功能。

## 交付约束

- 生产包不包含 `.env`、运行时数据库、日志、上传附件和演示数据。
- 部署前必须执行数据库迁移台账检查和 `php think system:check`。
- 真实钉钉免登、审批通知、HTTPS、备份恢复和六角色 UAT 仍需在目标环境完成。
