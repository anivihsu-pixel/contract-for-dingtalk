# v2.50.2 交付说明

> 历史说明：当前 v2.50.4 已移除商机模块，本文中涉及商机的内容不属于当前交付范围。

## 本次修复

- PC 与移动端均保留合同、客户、审批、商机的可见入口，并由服务端权限继续校验。
- 移动工作台的“新建”菜单可直接新建商机；“更多”页可进入商机管理。
- 移动端商机客户改为搜索选择；没有匹配客户时可新建，保存后自动返回商机表单并带回客户。

## 部署包

- `contract-dingtalk-v2.50.2.tar.gz` 是纯生产包：不含 `.env`、本地数据库、运行日志、上传附件或演示数据。
- 请使用包内 `scripts/deploy.sh` 在 Linux 服务器部署；首次部署前准备 MySQL、共享目录和 `.env`。
- Web 根目录应指向 `current/public/`；部署前配置 `APP_DEBUG=false`、`DINGTALK_MOCK_MODE=false`、HTTPS 与强密钥。

## 上线前验收

1. 执行 `php think system:check`，确认全部通过。
2. 分别用业务、部门经理、财务、项目执行、总经理、管理员账号验收 PC 与移动端入口和数据范围。
3. 验证移动端“商机 → 搜索/新建客户 → 返回商机 → 保存”的链路。
4. 验证真实钉钉免登、审批通知、HTTPS、备份与恢复演练。
