# 轻量商务经营管理系统开发计划

## 一、目标与边界

本次按全新部署开发，不保留历史数据迁移、旧字段兼容或旧审批规则回退。

产品定位为轻量商务经营管理系统：

- 商务人员用最少字段完成商机、合同、审批与回款跟进。
- 总经理通过经营周报掌握签约、回款、审批与风险。
- 管理员在后台自行设置审批流程、审批人和抄送对象；系统只负责自动匹配与执行。

## 二、合同经营分类

### 2.1 业务类型

将全系统的“主业务线”统一更名为“业务类型”。业务类型是商机、项目、合同共同使用的经营分类，也是审批规则和经营统计的核心维度。

默认业务类型：

- 活动服务
- 广告与内容服务
- 商品销售
- 其他

业务类型由管理员在后台字典维护，可调整名称、排序和启停。

### 2.2 移除法律类别

移除合同法律类别相关的：

- 数据字段
- 后台字典
- 新建及编辑表单
- 合同列表筛选和详情展示
- 导入、导出与报表
- 审批匹配逻辑

合同经营判断保留以下必要字段：

- 业务类型
- 收付款方向：销售收款、采购付款
- 交易属性：交易合同、非交易合同
- 金额、期限、客户、附件、合同概要和回款计划

## 三、合同创建与提交审批

### 3.1 创建入口

保留两个合同入口：

1. 商机转项目再转合同：自动带入客户、业务类型、负责人等信息。
2. 直接新建合同：不依赖商机或项目，可直接录入并提交审批，适用于续签、采购、临时合作等场景。

### 3.2 新建合同操作

新建合同仅保留核心信息填写，并提供两个操作：

- 保存草稿
- 提交审批

商务人员不选择审批流程。提交时由系统根据管理员配置自动匹配流程。

没有匹配流程时，系统提示“未配置适用审批流程，请联系管理员”，并保留合同草稿，不丢失已填写内容。

## 四、审批流管理与自动匹配

### 4.1 管理员配置范围

审批流程继续完全由管理员在后台配置，保留：

- 创建、编辑、复制、排序、启停
- 多审批节点
- 指定人员、角色、部门经理审批
- 会签、或签
- 转交、撤回、驳回、重新提交
- 抄送、通知和完整审批轨迹

系统不预置具体审批路径，也不替管理员生成审批人或抄送对象。

### 4.2 流程适用条件

每条审批流程可配置以下条件：

- 业务类型：可多选；留空表示适用全部。
- 收付款方向：销售收款、采购付款或全部。
- 交易属性：交易合同、非交易合同或全部。
- 合同金额区间。
- 流程优先级。

### 4.3 自动匹配规则

合同提交时按以下顺序自动匹配：

`业务类型 → 收付款方向 → 交易属性 → 金额区间 → 流程优先级`

如果同一优先级有多条流程同时命中，系统阻止提交，并提示管理员调整流程排序，避免合同走错审批流。

## 五、商机、项目与合同衔接

- 新建商机时选择业务类型。
- 商机转项目时自动带入业务类型。
- 项目转合同或从项目新建合同时自动带入业务类型。
- 直接新建合同时由商务人员选择业务类型。
- 合同在提交审批前可修改业务类型；提交后锁定。

## 六、回款管理

- 合同审批通过、签署或进入执行后，可维护回款计划。
- 支持应收金额、计划回款日期、实际回款日期、部分回款、已回款和逾期。
- 合同详情展示回款进度和未回款余额。
- 已逾期及未来七天到期未回款，纳入总经理经营周报的风险清单。

## 七、总经理经营周报

保留现有每周一自动生成、站内通知和钉钉推送，并将周报作为周一例会页面。

### 7.1 周报内容

- 上周新增合同数与签约金额。
- 上周实际回款、本月累计回款。
- 待回款金额、逾期金额及笔数。
- 待审批合同数、金额、待总经理审批数和审批超时数。
- 按业务类型统计签约、回款和待回款。
- 重点商机：预计金额、预计成交日期、负责人和下一步动作。
- 风险清单：逾期回款、未来七天到期未回款、大额审批中合同、长期未推进商机。

### 7.2 下钻能力

每个指标和风险项都可进入对应的合同、商机或审批详情，便于在周会中快速定位责任人和下一步动作。

## 八、全新部署初始化

- 更新 MySQL 与 SQLite 初始化脚本，直接使用新字段和新审批规则结构。
- 不保留法律类别字段，不编写历史数据迁移脚本。
- 初始化业务类型字典。
- 不预置具体审批流；审批流、审批人和抄送对象全部由管理员在后台设置。
- 未配置适用审批流时，允许保存草稿，并在提交时给出明确提示。

## 九、验收测试

1. 直接新建合同，分别验证保存草稿与提交审批。
2. 验证未匹配审批流时合同草稿不丢失、提示明确。
3. 配置多条审批流，验证业务类型、收付款方向、交易属性和金额区间的自动匹配。
4. 验证审批节点、会签、或签、转交、撤回、驳回、重新提交、抄送和通知。
5. 验证商机到项目到合同的业务类型自动带入。
6. 验证直接新建合同可独立完成审批和回款。
7. 验证部分回款、全额回款、逾期回款及经营统计。
8. 验证总经理经营周报中的经营数据、审批待办、风险清单及明细下钻。
